# TechZone - Premium E-Commerce Store

**[Live demo](https://techzone-shop1.vercel.app)**

A modern, premium e-commerce website for tech products featuring a stunning 3D scroll experience.

## Features

- **3D Product Showcase** - Interactive iPhone 3D model with scroll animations using React Three Fiber
- **Responsive Design** - Works perfectly on desktop, tablet, and mobile
- **Performance Optimized** - Adaptive quality tiers for low-end to high-end devices
- **Modern UI** - Glassmorphism design with smooth animations
- **Multiple Pages** - Home, Shop, About, Blog, Contact, Login, Cart
- **21 Products** - Phones, laptops, and accessories with realistic data

## Tech Stack

- React 19 + Vite
- Tailwind CSS v4
- React Three Fiber + Three.js
- GSAP ScrollTrigger
- React Router

## Quick Start

Requires **Node.js 20.19+ or 22.12+** (Vite 8's minimum).

```bash
npm install
npm run dev
```

## Build

```bash
npm run build     # production build
npm run preview   # serve the production build locally
npm run lint      # lint with ESLint
```

## Pages

- `/` - Homepage with 3D iPhone hero
- `/shop` - Product catalog with filters
- `/about` - About page
- `/blog` - Blog section
- `/contact` - Contact form
- `/login` - Login page
- `/cart` - Shopping cart
